## What was completed and verified
1. **Paper compiled with real LaTeX.** No local install was needed: the portable Tectonic binary was downloaded
   into `.tools/` (gitignored). Fixes made: unescaped `_` and `%` in generated tables; tables now wrap in
   `adjustbox`; Unicode λ, —, – mapped to LaTeX; appendix float barriers; a duplicated sentence and a mangled
   caption corrected; signed zeros suppressed. Final log: no undefined references or citations, no missing
   characters, 2 negligible overfull boxes (≤13 pt). All 30 pages were inspected visually.
2. **Website tested.** Python 67/67, frontend unit 42/42 and Playwright e2e 3/3 (rerun against the live local API)
   all pass, with clean lint and typecheck. Ten desktop pages and five mobile pages were checked, with no page
   errors. A 16 px mobile overflow (provenance tooltip; select min-width) was found and fixed.
3. **UI.** A "static deployment" banner was added, and runs on the static site refuse honestly with an explanation
   rather than failing silently or showing fabricated results. No scientific value was altered.
4. **Video rendered.**
   - Footage: the real website, including three live HiGHS runs captured from the local API (normal week,
     severe drought, drought + 300 MW battery; all Optimal), with programmatic camera moves.
   - Graphics: deterministic motion graphics (Natural Earth map, animated energy flows, KaTeX equations, result
     cards). Every number comes from `video/build/scene_numbers.json`, which is generated from the experiment files.
   - Audio and captions: original synthesised soundtrack (no third-party audio), no voice-over, on-screen
     narration plus SRT captions.
5. **GitHub.** The history, all 326 tracked files and their contents were scanned for secrets, tokens, keys and
   personal data: none were found. Before the first push, commit metadata was rewritten from a personal Gmail
   address to the GitHub no-reply address. `node_modules`, venvs, frames, logs and the SQLite registry are
   excluded. Licence check: all dependencies are permissive (MIT/BSD/ISC). Data terms are recorded in `NOTICE.md`
   (NASA POWER acknowledgement, Open-Meteo CC BY 4.0, Natural Earth public domain); code is MIT (`LICENSE`).
6. **Deployment.** Netlify serves the production build plus JSON snapshots generated by the real API from the 24
   reference experiments; nothing is hand-written. Tested: page loads, navigation, charts, the provenance badge,
   paper/poster/video downloads, experiment JSON/CSV downloads and the mobile layout.
7. **Poster.** The placeholder was replaced with a QR code for the live site; it was decoded from the PDF to confirm.
8. **Research audit.** 26/26 headline claims match the experiment files. The data limitations remain visible in the
   README, the paper, every website page, the video and the poster.
